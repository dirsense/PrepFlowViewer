Quick Start Guide

Understand your flow at a glance.

Open and inspect Tableau Prep flows instantly, without loading source data.
You do not need Tableau Prep installed to view a flow.

Red outlines show where to click. Click any image to enlarge it. Screenshots use a sample flow.

1 Open2 Explore3 Edit & save4 ShareRun & publishTroubleshooting

1Open a flow

  1. Right-click the downloaded ZIP and select Extract All.
  2. Open PrepFlowViewer_v1.0.exe in the extracted folder.
  3. Select Open flow and choose a .tfl / .tflx file. You can also drag and drop a file onto the window.

Keep the _internal folder alongside the EXE. Move the entire folder if needed. For Windows 10 / 11 (64-bit).

2Select a step to explore

  • Use Fields to inspect columns, Changes to review calculations and transformations, and Settings to check connections and outputs.
  • Drag the flow map to pan and use the mouse wheel to zoom. Click icon ① below, or double-click an empty area, to fit the entire flow.

The Viewer shows the flow structure and settings, not actual data values or calculated results.

3Confirm your edits, then save

To edit a formula, follow these steps.

Open the formula and confirm your changes

Save to a file

Confirming changes does not save the file. Use Save flow before closing the Viewer to keep your edits.

Closing the editor before confirming discards your input. After confirming, use Undo / Redo in the top toolbar to undo or redo changes.

Change an output destination

Select an output step and open its Settings tab.

4Export an HTML viewer

Double-click the exported HTML file to open it in a browser. You can view it on a computer without Tableau Prep installed.

The HTML is read-only: you cannot edit or run flows in it. It includes connection details and formulas, so check its contents before sharing.
Export multiple flows to HTML

In the Batch export tab, add files or folders, choose a destination, and click Batch export HTML. Existing HTML files with the same names will be overwritten.

Run or publish a flow

These steps are optional if you only want to view, edit or share flows as HTML.

Run a flow
  1. Click the triangle icon in the top toolbar.
  2. Check Tableau Prep Builder and the output destinations. Select a credentials file if needed.
  3. Click Run for an individual output, or Run all. Progress and results appear in a separate dialog.

Tableau Prep Builder with a valid license is required. Running a flow updates data at the output destinations. Cancelling a run does not undo data that has already been written.

Publish a flow to Tableau Server
  1. Click the upward arrow in the top toolbar.
  2. Enter the Server URL, token name and token secret, then click Test authentication. About personal access tokens
  3. Check the publish name and destination, then click Publish.

The default site is used. A flow with the same name in the same destination is overwritten. Publishing does not save the flow file on your computer; use Save flow separately if needed.

Troubleshooting

The app will not start

Check that you extracted the ZIP and that the _internal folder is alongside the EXE. Microsoft Edge WebView2 is required to display the window. If an error appears, check its message.

Save flow is disabled

Click Confirm changes in the editor. Saving is available only when there are unsaved changes. Exported HTML files do not support editing or saving flows.

My edits disappeared

Closing the editor without clicking Confirm changes discards your input. Even after confirming, closing the Viewer without saving the file discards your changes.

A message says the file has changed

The original flow was updated by another app or process. Copy any formulas you want to keep, then reopen the flow and check its contents.
