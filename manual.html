01 / OVERVIEWはじめに

PrepFlow Viewerは、Tableau Prepのフローファイル（TFL / TFLX）の構造と加工内容を確認するツールです。Tableau PrepやPythonをユーザーのPCにインストールせずに使えます。

◎

構造を読む

ステップのつながり、フィールド、計算式、フィルター、結合・ピボット・集計の設定を確認します。

✎

計算式を直す

式を拡大して編集し、確定・Undo / Redo・フロー保存で変更を管理します。

↥

共有・公開する

閲覧専用のHTMLを渡す、またはTableau Serverにフローをパブリッシュします。

表示するのはフローの定義です。
閲覧時にデータソースへ接続したり、フローを実行したりはしません。実データのプレビュー、集計結果、件数・NULL率などは表示しません。実行ボタンから実行すると、Tableau Prep Builderが実データへ接続して出力先を更新します。パブリッシュ時には、指定したTableau Serverへ通信します。

この説明書の図について

図は操作を説明するための模式図です。売上フロー.tflx、[売上]、プロジェクト名などは説明用の例です。実際の画面では、開いたフローの名前や定義に置き換わります。

02 / GET STARTED起動して、フローを開く

  1. a.zipとb.zipを7-Zipで展開する

    案内されたパスワードを使い、2つのZIPを同じフォルダーへ展開します。ZIPの中から直接EXEを実行しないでください。

  2. 好きな場所へフォルダーを置く

    例：ドキュメント内のツール用フォルダー。EXEと_internalは一緒に置きます。

  3. PrepFlowViewer_v1.0.exeを開く

    専用ウィンドウが開きます。黒いコマンド画面は出ません。

  4. TFL / TFLXを選ぶ

    「＋ フローを開く」を押すか、ファイルを画面にドラッグ＆ドロップします。

PrepFlowViewer/
├─ PrepFlowViewer_v1.0.exe  ← 起動する
├─ _internal/          ← 一緒に置く
├─ 操作ガイド.html     ← 別途添付された場合
├─ はじめに.txt
└─ publish.example.ini

Windows 10 / 11（64ビット）向け。画面にはMicrosoft Edge WebView2を使用します。Python・Tableau Prep・Codexは不要です。

a.zipには_internal、b.zipにはEXEを収録しています。操作ガイド.html・はじめに.txt・publish.example.iniは補助ファイルとして別途添付します。説明書が別の場所にあってもViewerは起動できます。

初回と2回目以降の違い

初回：空の画面から開始

履歴がなければ、空のマップと右側の「使い方」タブを表示します。最初のフローを開いた直後も、ステップ未選択で「使い方」を表示します。

次回：直近のフローを自動表示

最近開いたフローを最大10件保持し、存在する最新のファイルを読み込みます。ステップ未選択で「フロー情報」を表示します。なくなったパスは履歴から除外します。

上部のファイル名のプルダウンから履歴を切り替えます。ファイル名の横には灰色でパスの末尾を表示します。選んだ後にファイルが見つからなかった場合は、エラーを表示して一覧から外します。

ドラッグ＆ドロップで開いたとき
デスクトップ版では元ファイルの場所を取得し、保存場所と最近のフローに反映します。通常のブラウザー版では元パスを取得できないため、「フローを保存」で保存先を決めると履歴に追加します。一度に複数を落とした場合は先頭の1ファイルを開きます。

読み込み直後は、ステップ未選択

開き方最初に表示するタブ

書き出したHTMLを開く使い方

どの場合も、入力ステップなどを自動選択しません。確認したいステップを自分でクリックします。

終了するには

専用ウィンドウ右上の×を押します。Viewerの裏の処理も終了します。未保存の編集があれば確認を表示し、処理中は終了を止めます。この説明書や、書き出したHTMLのブラウザー画面を閉じても、別に開いているViewerは終了しません。

04 / NAVIGATIONフローをたどる

図を見やすく動かす

  • 空白をドラッグ：フロー図を移動します。
  • ホイール：ポインター付近を基準に拡大・縮小します。
  • 空白をダブルクリック：全体表示に戻します。
  • 左右の境界線をドラッグ：詳細パネルの幅を調整します。

前後の処理へ移動する

詳細パネル上部の← / →で前・次のステップへ移動します。接続先が複数ある場合は候補一覧が開くので、進みたいステップを選びます。移動先がなければボタンは無効です。

全体の情報に戻る

ファイル名、保存場所、ステップ数・加工数・計算式数などは、ステップ未選択時の「フロー情報」で確認できます。保存場所が分かるときは「保存場所を開く」でエクスプローラーを開けます。

選択中のステップをもう一度押すか、マップの空白をクリックすると、選択を解除して右側の「フロー情報」に戻ります。未選択時は「フロー情報」「接続情報」「使い方」を切り替えられます。「接続情報」では接続元ごとに入力ステップを開き、「ステップの接続設定を表示」から詳細へ移動できます。

全体表示と、手動の拡大・移動

全体表示中は、右側パネルの幅や画面サイズに合わせて図を収め直します。手動で拡大・移動した後は、パネル幅を変えても倍率と位置を維持します。ホイールは細かく倍率を変えられます。操作案内は画面下端に表示し、定義の解析時間は「フロー情報」で確認できます。

タイトルと加工アイコン

タイトルは画面上で最低14px、コメントは最低13px、ステップ上の加工アイコンは最低16pxを確保します。タイトルは空き幅に合わせて最大2行に折り返し、省略された場合だけステップにマウスを置くとタイトル全文を表示します。

ステップのコメント

吹き出しアイコンを押すと本文の表示・非表示を切り替えます。初期状態はフローに保存された表示設定を反映します。保存座標を基準に閲覧用の間隔を設けており、コメントの開閉や長さでステップを縦に押し広げることはありません。元のフローファイルも変更しません。

状況表示方法
縮小して横幅が足りない現在のフォントで全角8文字分の幅が取れなければ本文を表示しません。半角・全角を単純に数える条件ではありません。
周囲に空きがある空き領域に応じた行数を表示します。縮小時に一律3行などの上限は設けません。
フローマップの下端にある下端から最大10行分の追加領域を使えます。他のステップや線との重なりは避けます。
接続線・他のステップと重なる重なる手前で省略します。先頭行がぶつかる場合は、近くの空き位置へ少し横にずらすこともあります。表示領域を確保できなければ本文は非表示です。
コメントが省略されている本文または吹き出しアイコンにマウスを置くと全文を表示します。本文が出ない場合も、表示をオンにした吹き出しアイコンから確認できます。
全体表示はステップ配置を基準に収めます。下端から伸ばした長いコメントまで画面内に収まるとは限りません。下の続きを読みたいときはマップを移動するか、吹き出しアイコンにマウスを置いて確認してください。

計算式を編集する手順

  1. ↗ で対象の式を開く

    編集したいステップ・フィールドであることを確認します。

  2. 式の文字を編集する

    入力を変更すると「変更を確定」が現れます。入力中はCtrl+Z / Ctrl+Yなどで、その式の編集を戻せます。

  3. 「変更を確定」を押す

    Viewer内の変更として反映されます。ここではまだTFL / TFLXは上書きしません。

  4. 上部のダウンロード →「フローを保存」でファイルに残す

    保存先とファイル名を指定します。詳しくは次の章へ。

編集できるのはViewer本体です。
書き出したHTMLの式は閲覧専用です。編集カーソルや「変更を確定」は表示しません。また、Viewerでも式の保存元を一意に特定できない場合は確定できません。式の実行・Tableauによる構文検証は行いません。
確定せずに閉じた編集は破棄します。
×・Esc・ポップアップ外のクリックで閉じると、その未確定の入力は取り消されます。開き直すと最後に確定した式に戻り、破棄した入力は上部のUndo履歴にも入りません。既に確定していた変更は残ります。必要な編集は閉じる前に「変更を確定」してください。

08 / SAVE & HISTORY「確定」と「保存」は別の操作

式を入力した段階、Viewerに確定した段階、元のフローファイルに保存した段階を分けて考えると、変更の行き先が分かります。

小さなデモで確かめる

以下は説明書のデモです。実際のViewerやフローファイルには影響しません。

① 入力中の計算式[売上] * 1.1ポップアップ内
② Viewerの確定内容[売上] * 1.1Viewerを閉じると失われる未保存分
③ フローファイル[売上] * 1.1ディスクに残る内容
まず「式を1.2に編集」を押してください。まだ3つとも同じ内容です。

複数の式の変更を戻す

ヘッダーのUndo / Redoは常時表示し、履歴ができると使えるようになります。Undo / Redoは、現在のフローで確定した複数の計算式の変更を順番に戻す・やり直す操作です。操作した対象の式がポップアップで開きます。

履歴がない状態でもボタンの領域は残ります。操作できないボタンは無効表示です。Undo後に別の変更を確定すると、それより先のRedo履歴は置き換わります。保存に成功すると確定履歴はリセットされます。

保存ダイアログで選ぶこと

保存方法結果
同じ場所・同じ名前で保存元のフローファイルを上書きします。保存画面で上書き確認が出た場合は内容を確認します。
別の名前・場所で保存別ファイルとして保存し、Viewerもそのファイルを編集対象にします。最近開いたフローにも追加します。
保存画面でキャンセルファイルは変更しません。Viewer内の確定済みの変更は残ります。
元のファイルと同じ拡張子で保存します。読み込み後に他のアプリで元ファイルが更新されていた場合は、上書きを止めてエラーを表示します。

09 / SHARE AS HTML「HTMLを保存」で、閲覧用に共有する

「フローを保存」はTableau Prep用のファイルを保存する操作です。「HTMLを保存」は、その時点でViewerに反映されている内容を、ブラウザーで読める閲覧用のファイルにする操作です。

操作反映先元TFL / TFLXを書き換える？
変更を確定Viewer内のメモリ書き換えない
フローを保存指定したTFL / TFLX同じ保存先を選べば上書き
HTMLを保存新しく書き出す閲覧用HTML書き換えない
パブリッシュTableau Serverのフローローカルの元ファイルは書き換えない

保存メニューと一括変換

上部の下向き矢印から「HTMLを保存」「HTMLを一括保存」「フローを保存」を選びます。フローの保存は編集内容を確定すると使えます。

  1. 「HTMLを一括保存」を開き、複数のTFL / TFLXをフォームへドロップするか、「ファイル指定」「フォルダー指定」で追加します。サブフォルダーを含めるか選べます。
  2. 保存先フォルダーを選び、「HTMLに変換して保存」を押します。
  3. ファイルごとの成功・失敗を確認します。失敗しても残りを続けます。「このファイルまでで停止」で、次のファイルから停止できます。

変換にはファイルの保存済み内容を使います。画面で編集中の内容は先にフローへ保存してください。同名のHTMLは上書きします。異なるフォルダーの同名フローも後のものが上書きします。元フローと現在の画面・編集履歴は変更しません。

HTMLを受け取った人ができること

HTMLをブラウザーで開くと、ステップ未選択で「使い方」を表示します。そこからフロー図や詳細タブを見たり、計算式を拡大・自動整形表示・コピーしたりできます。括弧の対応強調も使えます。Viewer一式やPythonは不要です。

計算式編集・変更確定・Undo / Redo・フロー保存・実行・パブリッシュはできません。元TFLXのパスが情報として残っていても、そこから再読込する仕組みではありません。絶対パス・相対パスへの依存で閲覧できなくなることはありません。

共有したい編集は、先に「変更を確定」してください。まだポップアップ内で入力しているだけの内容はHTMLへ反映されません。HTML保存はローカルのフロー保存の代わりにはなりません。

HTMLにはフロー定義に含まれる接続情報・計算式・フィルター値などが入ります。実データの抽出や添付データ一式をそのまま含めるものではありません。共有する相手に見せてよい内容か確認してください。

出力ステップを選んで実行する

上部の三角アイコンを押すと、出力ステップ名・保存先・ファイル名を確認できます。各行の「実行」はその出力だけ、「すべて実行」は全出力を一度に実行します。

  1. Tableau Prep Builderが自動検出されているか確認します。別の版を使う場合や見つからない場合は「変更」で scripts/tableau-prep-cli.bat を選びます。
  2. 必要な場合だけ、Prep CLI用の認証JSONを選びます。パブリッシュ用PAT設定とは別です。認証ファイルの選択はViewerの終了まで保持します。
  3. 実行する出力を選びます。出力が多い場合は一覧内をスクロールできます。
  4. 別のポップアップで実行状態・経過時間・ログを確認します。終了後は所要時間が残り、「前回の実行結果」から再確認できます。

実行中は「キャンセル」でViewerが起動した実行プロセスを停止できます。既に書き込まれたデータは元に戻りません。

確定済みの編集を含む一時コピーで実行し、元フローと編集履歴は変更しません。個別実行では、選ばなかった出力ステップとその参照・表示設定をコピーから除きます。一時コピーは元フローと同じフォルダーに作成して終了後に削除するため、フォルダーへの書き込み権限が必要です。

実行にはTableau Prep Builderと利用可能なライセンスが必要です。実行すると実データへ接続し、出力先をフローの書き込み設定に従って更新します。現在は完全更新・保存済みのパラメーター値を使います。実行中はフロー切替や編集を止め、画面を再読み込みしても同じ実行のログに戻ります。

10 / PUBLISHTableau Serverへパブリッシュする

全体表示の右にある上向き矢印を押します。これはViewer限定の機能です。接続するServerで有効なパーソナルアクセストークン（PAT）と、公開先への権限が必要です。

  1. 編集中の式を「変更を確定」する

    未確定の式があると、先に確定するよう案内します。ファイルへ保存する前でも、確定済みの編集を含めて公開できます。

  2. Server URL・トークン名・トークン値を入力する

    Server URLはサーバーのURLです。ブラウザー内の画面URLに含まれる #/site/… などは入れません。サイトは既定サイト（空のsite_id）固定で、選択欄はありません。

  3. 「認証テスト」で接続を確認する

    サインインしてサインアウトします。フローは公開しません。成功すると完了ログを表示し、上3項目を設定ファイルへ保存します。認証成功だけでは公開権限まで保証しません。

  4. 公開名と公開先を確認する

    公開名は、開いているファイル名から拡張子を除いたものが初期値です。公開先は 親プロジェクト/子プロジェクト。最上位だけなら 営業部 のように入力します。

  5. 「パブリッシュ」を押す

    認証・プロジェクトの階層検索・アップロードを順に実行します。実行ログを確認し、完了するまで待ちます。同じ公開先・同じ名前のフローは上書きします。

Serverへの公開と、PC上のフロー保存は独立しています。
公開時は確定内容を含む一時コピーを使います。公開に成功しても、PC上の元TFL / TFLXは変わらず、Viewerの未保存状態も解除されません。PCにも残したい場合は「フローを保存」してください。

パブリッシュ先が空欄になる理由

フロー自体の公開設定から、明示的で一意なプロジェクトパスを取得できた場合だけ初期表示します。情報がない・特定できない場合は空欄です。出力ステップが持つデータソースの公開先を、フローの公開先として流用はしません。

画面が低いときのフォーム

ダイアログは画面の高さに合わせて表示し、実行ログの高さを調整します。ログが長くなるとログ内をスクロールできます。フォーム自体が収まらない小さな画面では、ダイアログ全体もスクロールできます。

実行ログの読み方

表示意味・次の操作
認証中…指定したServerに接続しています。認証が通らなければ、URLとPATを確認します。
公開先を検索中…名前と親プロジェクトで階層を絞り込んでいます。見つからない場合は、綴り・階層・閲覧権限を確認します。
パブリッシュ中…フローをアップロードしています。大きいTFLXは時間がかかる場合があります。
完了・フローID公開処理が成功しています。必要に応じてServer側で内容を確認します。
通信が途切れた公開が完了している可能性もあります。すぐ再実行せず、Server側の結果を確認します。

公開はフローをServerへ登録する操作で、フロー実行の指示ではありません。自動テストではモックとローカル模擬Serverを使います。接続先の設定や権限によって結果が変わるため、公開結果は実行ログで確認してください。

11 / FILES & SETTINGS設定ファイルと保存場所

publish.ini：認証情報の初期値

配布版ではPrepFlowViewer_v1.0.exeと同じフォルダーに置きます。設定がなければフォームの上3項目は空欄です。認証テストまたは公開の成功時に新規作成・上書きし、失敗した認証情報では更新しません。

[tableau]

token_name = YOUR_TOKEN_NAME
token_value = YOUR_TOKEN_VALUE

トークン値は画面では伏せ字ですが、publish.iniには平文で保存します。認証情報入りの設定ファイルは、ツールを他の人へ配布するときに含めないでください。HTMLや実行ログに、この設定のトークンを埋め込むことはありません。

12 / TROUBLESHOOTING困ったときは

症状に近い項目を開いてください。印刷するときは、すべての回答が表示されます。

EXEを開いてもViewerが起動しない

ZIPを展開済みか、EXEの隣に_internalがあるかを確認します。Windows 10 / 11の64ビット環境とMicrosoft Edge WebView2が必要です。表示された起動エラーがあれば、その内容を確認してください。配布版ではPythonの追加インストールは不要です。

最近のフローからファイルが消えた

ファイルが移動・削除された場合、存在しないパスを履歴から除外します。「フローを開く」から現在の場所を選び直してください。デスクトップ版ではドラッグ＆ドロップしたファイルも履歴に追加します。通常のブラウザー版では保存先を確定するまで元のパスで履歴に追加されません。

図が小さすぎる・画面外へ移動してしまった

⛶ 全体表示を押すか、図の空白をダブルクリックします。特定の部分だけを読みたいときは、その付近でホイールを回して拡大してください。

縮小するとコメントが消える・途中までしか見えない

本文を表示するには全角8文字分の幅が必要です。さらに、接続線・ステップ・タイトルなどとの重なりを避けています。拡大やマップ移動で見やすくするか、表示をオンにした吹き出しアイコンにマウスを置いて全文を確認してください。

×で閉じたら入力した計算式が元に戻った

「変更を確定」を押さずに閉じた入力は破棄する仕様です。上部のUndoにも追加しません。変更を残すときは、確定してから「フローを保存」してください。

別のディスプレイへ移すと文字がぼやける

現在のWindows配布版は、ディスプレイごとの表示倍率に対応しています。古いEXEを使っていないか確認し、最新版を起動し直してください。解消しない場合はWindows側の解像度・表示倍率も確認します。

「計算式」「フィルター」などの分類が見つからない

そのステップで0件の分類は表示しません。また、型変更は「その他」、式を使うフィルターは「フィルター」に分類します。すべての処理を見たいときは「すべて」に切り替え、検索欄を空にしてください。

「変更を確定」「フローを保存」が出ない・押せない

まずViewer本体か、閲覧専用HTMLかを確認します。入力を変えないと「変更を確定」は表示されません。確定済みの変更があるとヘッダーの保存領域が現れます。すべてUndoした場合は未保存変更がないため保存ボタンが無効になり、Redo用の履歴は残ります。式の保存元を特定できない場合も確定できません。

保存後のHTMLに、入力した式が反映されていない

ポップアップ内の編集を「変更を確定」してからHTMLを書き出してください。以前に書き出したHTMLは自動更新されません。最新の内容で再度HTMLを保存します。

フロー保存で「ファイルが変更されています」と出る

読み込み後に元ファイルが他のアプリなどで更新されています。外部の変更を誤って上書きしないため保存を止めています。必要な計算式をコピーして控え、ファイルを開き直して内容を確認してください。

保存場所が出ない・「保存場所を開く」がない

デスクトップ版はドラッグ＆ドロップでも元の保存場所を表示します。通常のブラウザー版では元のフルパスを取得できません。フローを保存して場所を確定するか、「フローを開く」でファイルを選んでください。書き出したHTMLから元の保存場所を開く機能はありません。

認証テストが失敗する

Server URL、PATのトークン名・値、有効期限や失効状態、Serverへの接続環境を確認します。現版は既定サイト固定です。エラーログが証明書や権限に関する内容なら、そのServerの管理者へ確認してください。

認証できるのにパブリッシュ先が見つからない

プロジェクトの名前と階層を確認します。親/子の区切りはスラッシュです。Windowsのフォルダーパスではありません。ログインできても、そのプロジェクトの閲覧・公開権限がなければ処理できません。

パブリッシュできたのに「フローを保存」がまだ有効

Serverへの公開は、PC上のファイル保存とは別です。ローカルにも変更を残すなら、あらためて「フローを保存」を押してください。公開だけではUndo / Redo履歴もリセットしません。

通信エラー・Failed to fetchが出る

開発用のブラウザー版では、裏のローカルサーバーが停止していないか確認します。専用ウィンドウ版でも、処理中の内容がある場合は不用意に再読み込みせず、必要な式を控えてください。パブリッシュ中の通信断では、再実行前にServer側の公開結果を確認します。
