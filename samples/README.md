# Sample flows

Only these two flows are included:

| File | Source and purpose |
| --- | --- |
| `Superstore.tflx` | English Superstore sample supplied with Tableau Prep Builder 2026.2 (`help/Samples/en_US/Superstore.tflx`). Used for viewer demonstrations and compatibility tests. |
| `Demo_Tableau_Server_Connections.tflx` | Synthetic flow created for this project to test connection display. All names, servers and fields are fictitious. |

Superstore belongs to its respective rights holders; this repository does not grant additional rights to that sample. See the [Tableau tutorial](https://help.tableau.com/current/prep/en-us/prep_get_started.htm). Sample flows are not bundled in the Windows release ZIP.

Community-created Preppin' Data flows have been removed. Automated regression cases use small, original fixtures instead. The synthetic Server flow is for display testing, not live execution or publishing.
