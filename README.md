# PrepFlow Viewer

図解入りの詳しい説明書は [操作ガイド（HTML）](manual.html) を開いてください。配布版には `操作ガイド.html` として同梱します。オフライン閲覧・章の検索・操作デモ・印刷に対応しています。

Tableau Prep のフローファイルを、データソースに接続せずに読むローカルビューアーです。Pythonがフロー定義を解析し、HTML / JavaScript が画面を表示します。通常の閲覧にインターネット接続・Tableauの起動は不要です。

## 起動（配布版・Python不要）

`dist/v1.0_YYYYMMDD/` にある `a.zip` と `b.zip` を、7-Zipで同じフォルダーへ展開してください（パスワードは別途案内）。`_internal` と **`PrepFlowViewer_v1.0.exe`** が並ぶ状態でEXEをダブルクリックすると、専用ウィンドウが開きます。Python・Tableau Prep・Codexのインストールは不要です。

配布ZIPはビルド日のフォルダーに作成し、同じ版・同じ日付では上書きします。パスワードは開発環境の `build-password.txt` から読み込み、配布ZIPには含めません。バージョンは明示的な指定があるまで `1.0` を維持します。

展開したフォルダーは好きな場所へ移せます。`_internal` も同じフォルダーに置いたまま使ってください。黒い画面は開きません。Viewer右上の×を押すと、裏の処理も一緒に終了します。未保存の編集がある場合だけ終了確認を表示します。初回は空の画面、次回からは直近に開いたフローを表示します。

ソースコードから起動する開発者だけは、Python 3.10以降を用意して `start_viewer.cmd` を使用します。

- 上部バーには最近開いたフローを新しい順に最大10件表示します。ファイル名と末尾を優先して省略したパスを表示し、存在しなくなったファイルは起動時・一覧表示時に除外します。履歴は `%LOCALAPPDATA%/PrepFlowViewer/recent-flows.json` に保存します。
- ドロップしたファイルはブラウザから元の絶対パスを取得できないため、元ファイルの履歴には追加しません。「フローを保存」で保存先を確定すると履歴に追加します。
- `.tflx` または `.tfl` を画面にドラッグ＆ドロップするか、「フローを開く」で選択することもできます。
- ステップをクリックし、右側の「フィールド一覧」「変更内容」「設定」の3タブで確認します。設定タブ名はステップの種類に応じて変わります。
- ホイールでズーム、空白のドラッグで移動。「全体表示」で元に戻ります。
- 左右の境界線をドラッグすると詳細パネルの幅を変えられます。右上の × で閉じ、ステップ選択で再表示します。
- フィールドは「すべて／使用中／削除済み」で絞れます。削除した列は取り消し線、名前変更・型変更・計算などは変更アイコンで表示します。
- 変更内容には実行順の加工と計算式を表示します。コメント、フィールド参照、関数などを色分けし、式のコピーもできます。
- 計算式のポップアップでは「原文／自動整形」を切り替えて編集・コピーできます。「変更を確定」はメモリへの反映だけで、ファイルは変更しません。
- 確定後は上部にUndo／Redoと「フローを保存」が現れます。Undo／Redoは複数の計算式をまたいで操作でき、対象の式を開きます。
- 「フローを保存」は元のフォルダ・ファイル名を初期表示する保存ダイアログを開きます。別名保存後は、そのファイルが編集対象になります。ドラッグ＆ドロップの場合は元のフォルダをブラウザから取得できないため、保存先を選択してください。
- 長い式は変更内容タブで6行まで表示します。省略されている式だけに展開／折りたたみボタンが現れます。
- パネル内の検索でフィールド・変更内容を検索できます。変更アイコンを押すと該当する加工へ移動します。
- 「HTMLを保存」で、そのフローを単体HTMLに書き出します。保存したHTMLはPythonやサーバーなしで表示できます。
- 保存したHTMLは閲覧専用です。計算式の入力カーソル・変更確定・Undo／Redo・フロー保存は表示せず、式のコピー・拡大・自動整形・括弧の強調は利用できます。
- 配布版はViewerの×で終了します。開発用ブラウザー版はサーバーを Ctrl+C で終了します。

配布版はWindows 10/11（64ビット）とMicrosoft Edge WebView2で動作します。Python実行環境と画面用ライブラリは同梱しています。専用ウィンドウごとに空いているローカルポートを使用し、普段のブラウザーや開発用Viewerとは独立して終了します。

開発ツールからWindows版を起動する場合も、ファイル選択画面を表示できる通常のデスクトップ環境で実行してください。コンソールを出さずに起動する場合は `pythonw.exe` を使い、ウィンドウの起動指定は通常表示にします。`WindowStyle Hidden` は保存ダイアログの初回表示にも影響するため使わないでください。未保存の編集がある場合は、ブラウザーの再読み込みやサーバーの停止前に保存またはセッションの復元準備が必要です。

```powershell
python prepflow.py --serve
# ポートを変える場合
python prepflow.py --serve --port 8766
```

## HTMLへの一括変換

```powershell
python prepflow.py samples/Superstore.tflx -o output/Superstore.html
python prepflow.py "C:\flows\MyFlow.tflx" --open
```

`export_html.cmd` にフローファイルをドロップしても変換できます。引数なしで起動するとファイル選択画面が開きます。

## 表示する内容

- `flow`: ステップ、接続、入力フィールド、順序付き加工、計算式、結合条件、ユニオンの対応、集計、ピボット、出力先。
- `displaySettings`: 保存されたステップ座標と色。座標なしの場合は接続から自動配置。
- `maestroMetadata`: 形式のメタデータ・機能情報。
- ステップのコメントをフロー図に表示。吹き出しアイコンで個別に開閉し、コメント分の段間隔を再計算します。元のフローファイルは変更しません。表示用の折り返しに合わせた再配置のため、Prepと完全に同じピクセル配置ではありません。
- フィールドは入力定義から削除・追加・名称変更・型変更・結合・ユニオン・集計・列→行ピボットを追って復元します。
- 結合前の加工は左・右入力を区別し、型変換の `calc` も計算式として表示します。
- ユニオンの入力ごとに式が異なる場合、その違いを保持します。

## 現時点の対応範囲

`Superstore.tflx` を基準に実装しています。サンプルでは19ステップ・18接続線・70加工・16計算式（型変換の式2件を含む）を読み取ります。

**フィールド一覧は静的な復元であり、Tableauの実行結果ではありません。** 計算結果の値・件数・NULL率・分布は取得しません。

- 計算式のデータ型は、一部の単純な式のみ推定し、それ以外は「未確定」と表示します。
- 結合で重複するフィールド名の接尾辞は推定です。その注記は下流にも引き継ぎます。
- 行→列ピボットなど、データの値で出力列が決まる加工は正確な列一覧を取得できません。
- 未対応の新しいステップや複雑な内部分岐・グループは、警告と元のJSON定義を表示します。内部グループの展開表示は未実装です。
- `.tfl` はZIPパッケージ／JSONの両方を受け付けます。JSONだけの場合、保存座標がないため自動配置します。
- ローカルビューアーでは計算式を編集・保存できます。計算式の実行やTableauによる検証は行いません。単体HTMLではファイルへの保存はできません。

## データの扱い

サーバーは `127.0.0.1` のみで待ち受けます。アップロードしたファイルは保存用にこのPC上の一時領域で保持し、サーバー終了時に破棄します。表示時はフロー定義を読み、保存時は式を更新した定義と元の添付データをパッケージにまとめます。外部でファイルが更新されていた場合は上書きを中止します。ファイル名・内容はサーバーログに記録しません。

画面からの読込は2GBまで、各定義ファイルは展開後64MBまでです。大きなパッケージは変換コマンドから直接読むと、ブラウザからファイルを送る時間を省けます。

書き出したHTMLには接続情報・計算式・フィルターの値・置換設定など、定義に含まれる情報が埋め込まれます。

## 構成と検証

```text
prepflow.py        Pythonの解析・HTML生成・ローカルサーバー
web/viewer.html    画面の構造
web/viewer.css     表示スタイル
web/viewer.js      フロー描画・選択・検索・HTML保存
web/formula.js     計算式の字句解析・コメントの識別
tests/            解析・復元・安全なHTML埋め込みのテスト
samples/          サンプルフロー
output/           生成HTML（バージョン管理対象外）
```

```powershell
python -m unittest discover -s tests -v
node --check web/viewer.js
node tests/test_formula.js
node tests/test_comment_layout.js
```

Node.jsはJavaScriptの構文チェック用で、アプリの実行には不要です。

## Windows配布版の再ビルド（開発者向け）

Python環境で次を実行します。PyInstallerは開発用フォルダーだけに配置します。

```powershell
python -m pip install --target .build-tools pyinstaller==6.22.3 pywebview==6.2.1 tableauserverclient==0.41
python build_windows.py
```

`dist/PrepFlowViewer` と配布用ZIPを生成します。ユーザーのフロー、履歴、サンプル、テスト、開発用Pythonは配布物に含めません。画面と必要な実行環境・フォルダー表示用スクリプトだけを同梱します。

## Tableau Serverへのパブリッシュ

全体表示アイコンの右にある上向き矢印から開きます。エクスポートしたHTMLでは表示されません。

- Server URL、PATのトークン名・値を入力します。サイトは既定サイト（`site_id=''`）固定です。
- パブリッシュ名は現在のファイル名（拡張子なし）。公開先は `親プロジェクト/子プロジェクト` で指定します。フロー自体の公開設定に明示的なプロジェクトパスがある場合だけ初期値に使用し、出力データソースの公開先は使用しません。手元のサンプルには該当情報がないため空欄になります。
- 「認証テスト」はログイン・ログアウトのみ。「パブリッシュ」は現在のフローを同名上書きで公開します。確定した編集を含む一時コピーを使用し、ローカルの元ファイルは変更しません。公開しただけではローカルの未保存状態は解除されません。
- 認証テストまたは公開の成功時だけ、EXEと同じフォルダーの `publish.ini` に認証情報を保存します。ソース版ではこのリポジトリ直下です。あらかじめ配置する場合は `publish.example.ini` を `publish.ini` にコピーして記入します。
- 設定ファイルのトークンは平文です。画面では伏せ字にし、HTMLやログには含めません。配布ZIPには空の設定例だけを含めます。
- プロジェクト検索は名前と親（最上位は `topLevelProject`）でサーバー側を絞り込み、ページをたどります。フィルターに使えない `,` / `&` を含む名前は親で絞って完全一致を確認します。
- 実行ログをフォーム内に逐次表示します。本番サーバー接続は行わず、TSC 0.41の型を使ったモックとローカルAPIで検証しています。

参考: [TSC公開API](https://tableau.github.io/server-client-python/docs/api-ref#flowspublish)、[Tableauプロジェクト検索フィルター](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_concepts_filtering_and_sorting.htm#projects)。
