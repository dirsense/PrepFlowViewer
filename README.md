# PrepFlow Viewer

Tableau Prepのフローファイル（`.tfl` / `.tflx`）を読み、フローマップ・フィールド・加工・計算式を確認するWindows用ツールです。Viewer本体では計算式の編集、フロー保存、出力ステップごとの実行、Tableau Serverへのパブリッシュができます。閲覧専用の単体HTMLを書き出して共有することもできます。

**ドキュメント更新：2026年9月25日／配布版 v1.0**

図解・検索・操作デモ付きの [操作ガイド（HTML）](manual.html) も参照してください。配布用の名前は `操作ガイド.html` です。説明書はオフライン閲覧・印刷に対応しています。

## 起動する

Windows 10 / 11（64ビット）とMicrosoft Edge WebView2が必要です。配布版にはPython実行環境を含むため、Python・Tableau Prep・Codexの追加インストールは不要です。通常の閲覧はオフラインで利用できます。フローの実行には、利用可能なライセンスで動作するTableau Prep Builderを別途インストールしてください。

1. `a.zip` と `b.zip` を、案内されたパスワードを使って **7-Zipで同じフォルダーへ展開**します。
2. `_internal` と `PrepFlowViewer_v1.0.exe` が同じ階層にあることを確認します。
3. `PrepFlowViewer_v1.0.exe` を起動します。専用ウィンドウが開き、黒いコマンド画面は表示しません。
4. 「フローを開く」またはドラッグ＆ドロップで `.tfl` / `.tflx` を開きます。複数ファイルをドロップした場合は先頭の1ファイルを開きます。

フォルダーは任意の場所へ移せます。EXEと `_internal` は一緒に置いてください。`操作ガイド.html`、`はじめに.txt`、`publish.example.ini` は補助ファイルです。現在の分割ZIPは、`a.zip` に `_internal`、`b.zip` にEXEだけを収録するため、補助ファイルは配布フォルダーから別途添付してください。

終了はウィンドウ右上の×です。未保存の編集があれば確認し、処理中は終了を止めます。専用ウィンドウごとに空いているローカルポートを使うため、別のViewerや普段のブラウザーには影響しません。ディスプレイごとの表示倍率に対応しています。

## 読み込み直後の表示と履歴

**フローを読み込んでも、入力ステップなどを自動選択しません。** 右側の初期タブは次のとおりです。

| 開き方 | 初期タブ |
| --- | --- |
| 前回ファイルがなく、空の状態で起動 | 使い方 |
| 空のViewerで最初のフローを開く | 使い方 |
| 書き出したHTMLをブラウザーで開く | 使い方 |
| 起動時に前回のフローを自動で読み込む | フロー情報 |
| 既にフローがある画面で別のフローを開く・ドロップする・履歴から切り替える | フロー情報 |

- 最近開いたフローは新しい順に最大10件。存在しないファイルは履歴から除外します。
- 履歴は `%LOCALAPPDATA%\PrepFlowViewer\recent-flows.json` に保存します。
- **デスクトップ版のドロップ**は元のパスを取得し、履歴と保存場所へ反映します。
- **通常のブラウザー版のドロップ**は元の絶対パスを取得できません。「フローを保存」で保存先を決めると履歴へ追加します。

## フローマップと詳細を読む

- ステップをクリックすると詳細を表示し、関連する接続線を強調します。同じステップをもう一度押すか、マップの空白をクリックすると選択を解除して「フロー情報」に戻ります。
- 未選択時の右側には「フロー情報」「接続情報」「使い方」があります。「接続情報」では接続元ごとに入力ステップを確認し、その接続設定へ移動できます。
- 空白をドラッグして移動、ホイールでポインター付近を中心に細かく拡大・縮小します。空白のダブルクリックまたは上部の全体表示アイコンで全体を収めます。
- 左右の境界線で詳細パネルの幅を変更できます。全体表示中は幅に合わせて再調整し、手動で拡大・移動した後は倍率と位置を維持します。
- 画面下端にマップの操作案内を表示します。定義の解析時間は「フロー情報」で確認できます。

### タイトル・コメント

保存座標を基準に、閲覧用の間隔を設けて表示します。コメントの長さや開閉でステップを縦に押し広げることはありません。元ファイルの座標も変更しません。

- タイトルは画面上で最低14px、コメントは最低13px。ステップ上の加工アイコンは最低16pxを確保します。
- タイトルは周囲の空き幅に合わせて最大2行。省略時だけ、ステップにマウスを置くとタイトル全文を表示します。
- コメントの吹き出しアイコンで表示・非表示を切り替えます。初期状態はフローに保存された表示設定を反映します。
- **全角8文字分の幅が確保できない場合、コメント本文を表示しません。** 現在のフォントで幅を測るため、半角・全角が混じっていても単純な文字数判定にはなりません。
- 表示行数は周囲の空き領域に応じて決まります。マップ下端からは最大10行分の追加領域を使えますが、接続線や他のステップとの重なりは避けます。
- 先頭行が接続線などにぶつかる場合、近くの空き位置へ少し横にずらして表示を試みます。スペースが足りない場合は省略・非表示になります。
- 省略されたコメントは、本文または吹き出しアイコンにマウスを置くと全文を確認できます。本文が出ない場合も、表示をオンにした吹き出しアイコンから確認できます。

### フィールド・変更内容・設定

| タブ | 内容 |
| --- | --- |
| フィールド一覧 | フィールド名・型・計算式など。「すべて／使用中／削除済み」で絞り込み。削除済みは取り消し線で表示 |
| 変更内容 | 実行順の加工。「すべて／計算式／フィルター／その他」で分類し、フィールドや式を検索 |
| 設定（種類に応じて名称が変化） | 入力接続、左右の結合条件、ユニオンの対応、集計、ピボット、出力先・書き込みオプションなど |

入力ステップを選ぶと「フィールド一覧」、結合・ピボット・出力は設定タブ、それ以外は「変更内容」が最初に開きます。前後の矢印で接続先へ移動でき、候補が複数あるときは一覧から選びます。

## 計算式を編集する

一覧の式は最大6行で表示し、省略される式だけ展開・折りたたみボタンを表示します。拡大ボタンでポップアップを開き、「原文／自動整形」を切り替えて読めます。コピー、色分け、対応する括弧の強調にも対応しています。

1. 対象の式を拡大して編集します。入力中は `Ctrl+Z` / `Ctrl+Y`（または `Ctrl+Shift+Z`）で、その式の入力を戻す・やり直すことができます。
2. **「変更を確定」を押すとViewer内へ反映**します。元のフローファイルはまだ変わりません。
3. 上部のUndo / Redoで、複数の計算式にまたがる確定変更を戻す・やり直すことができます。対象の式が開きます。
4. 上部のダウンロードアイコン →「フローを保存」で保存先を選び、TFL / TFLXへ保存します。別名保存後はそのファイルが編集対象になります。保存成功時に確定履歴をリセットします。

**確定せずに×・Esc・ポップアップ外のクリックで閉じると、その未確定の編集は破棄します。** 開き直すと最後に確定した式に戻ります。破棄した入力は上部Undoの対象になりません。先に確定していた変更は残ります。

「自動整形」を見るだけでは変更になりません。そこで編集して確定した場合は、その編集内容を反映します。保存元を一意に特定できない式は確定できません。計算式の実行やTableauによる構文検証は行いません。

## 保存・共有・公開の違い

上部の下向き矢印（ダウンロード）から「HTMLを保存」「HTMLを一括保存」「フローを保存」を選びます。Undo / Redoは実行アイコンの右に常時表示し、履歴がないときは無効です。三角の実行アイコンから、出力ステップを選んでフローを実行できます。

Windowsの保存・ファイル選択・フォルダー選択は、アドレスバーと検索欄がある標準の選択画面を使います。HTML保存もViewer側で保存先を選ぶため、EXE版でも通常のブラウザーで開いた場合でも同じ操作です。

| 操作 | 反映先 | PC上のフローファイル |
| --- | --- | --- |
| 変更を確定 | Viewer内の変更・Undo履歴 | 変更しない |
| フローを保存 | 指定したTFL / TFLX | 同じ場所・名前なら上書き |
| HTMLを保存 | 確定内容を含む閲覧用の単体HTML | 変更しない |
| パブリッシュ | Tableau Server上のフロー | 変更しない |

フロー保存をキャンセルしても、確定済みの編集はViewer内に残ります。読み込み後に元ファイルが外部で更新されていた場合は、上書きを止めます。

保存したHTMLはPython・Viewer・ローカルサーバーなしで開けます。フロー図、検索、詳細、式のコピー・自動整形表示などを使えますが、編集・Undo / Redo・フロー保存・実行・パブリッシュはできません。元ファイルを移動しても閲覧でき、元ファイルの更新は自動反映しません。

## HTMLの一括保存

1. ダウンロードアイコン →「HTMLを一括保存」を開きます。
2. 複数のTFL / TFLXをフォームへドロップするか、「ファイル指定」「フォルダー指定」で追加します。フォルダーはサブフォルダーも含めるか選べます。
3. 保存先フォルダーを指定して「HTMLに変換して保存」を押します。

選択したファイルの保存済み内容を、元ファイルと同じ名前のHTMLに変換します。同名のHTMLは上書きします。異なるフォルダーにある同名フローも、後から変換した内容で上書きします。画面で編集中の内容を含めたい場合は、先にフローを保存してください。

成功・失敗はファイルごとに表示し、失敗しても残りを続けます。「このファイルまでで停止」で次のファイルから停止できます。元フローと、現在開いているフローや編集履歴は変更しません。

## フローを実行する

1. 上部の三角アイコンから実行画面を開きます。出力ステップ名、保存先フォルダー、出力ファイル名を確認できます。
2. Tableau Prep Builderは標準のインストール先から自動検出します。見つからない場合や別の版を使う場合は「変更」で `scripts/tableau-prep-cli.bat` を選択します。
3. データベース・Tableau Serverなどの接続で必要な場合は、Prep CLI形式の認証JSONを選択します。Viewerのパブリッシュ用PAT設定とは別です。選択はViewerを終了するまで保持します。
4. 各出力の「実行」でその出力だけ、「すべて実行」で全出力を一度に実行します。出力が多い場合は一覧内をスクロールできます。
5. 実行すると別のポップアップに実行状態・経過時間・ログを表示します。終了後は所要時間が残り、「前回の実行結果」から再確認できます。

実行中は「キャンセル」でViewerが起動した実行プロセスを停止できます。既に書き込まれたデータは元に戻りません。

確定済みの計算式編集を含む一時コピーを使い、個別実行では他の出力ステップとその参照・表示設定だけを除きます。元フローと編集履歴は変更しません。相対パスの基準を維持するため、一時コピーは元フローと同じフォルダーに作り、完了後に削除します。そのフォルダーへの書き込み権限が必要です。

**実行は実データへ接続し、出力先をフローの書き込み設定に従って更新します。** 更新は完全更新で、パラメーターはフローの保存値を使います。増分更新やパラメーターの上書き指定は現在ありません。実行中は別の実行・フロー切替・編集を止め、ブラウザーを再読み込みした場合は同じ実行のログを再表示します。

[Tableau公式のCLI実行手順](https://help.tableau.com/current/prep/ja-jp/prep_run_commandline.htm)

## Tableau Serverへパブリッシュする

全体表示アイコンの右にある上向き矢印から開きます。Viewer本体限定です。

1. Server URL、PATのトークン名・値を入力します。**サイトは既定サイト固定**で、サイト選択欄はありません。
2. 「認証テスト」でログイン・ログアウトを確認します。フローは公開しません。
3. パブリッシュ名と公開先を確認します。名前の初期値はファイル名（拡張子なし）、公開先は `親プロジェクト/子プロジェクト`。最上位だけならその名前を入力します。
4. 「パブリッシュ」を押し、フォームの実行ログで結果を確認します。**同じ公開先・同じ名前のフローは上書きします。** フローを実行する操作ではありません。

確定済みの編集を含む一時コピーを公開します。公開だけではPC上の未保存状態やUndo履歴は解除しません。公開先の初期値は、フロー自体に明示的で一意なプロジェクトパスがある場合だけ使用します。出力データソースの公開先は流用しません。

フォームは画面の高さに合わせて表示し、実行ログ領域を調整します。ログが長いときはログ内を、画面が小さくフォーム全体が収まらないときはダイアログをスクロールできます。

認証テストまたは公開成功時に、Server URL・トークン名・値をEXE横の `publish.ini` に保存します。ソース版はプロジェクト直下です。手動で用意する場合は `publish.example.ini` をコピーします。**トークンは設定ファイル内では平文**です。認証情報入りのファイルは配布物に含めないでください。設定のトークンをHTMLや実行ログへ埋め込むことはありません。

## 対応範囲とデータの扱い

- `flow` の処理定義、`displaySettings` の配置・色・表示設定、`maestroMetadata` のメタデータを読みます。
- `.tfl` はZIPパッケージとJSONの両方を受け付けます。保存座標がなければ接続から自動配置します。
- **フィールド一覧は定義からの静的な復元で、Tableauの実行結果ではありません。** 入力フィールドの定義不足や複雑な加工では実際のデータソースと一致しない場合があります。表示設定だけから完全な列一覧を保証するものでもありません。
- 名前変更・削除・型変更・計算・結合・ユニオン・集計・列から行のピボットなどを追います。結合前の左右の加工や、ユニオン入力ごとの式の違いも表示します。
- 型の推定は対応する式に限ります。判定できない型は「未確定」、復元に不確かさがある場合は注記を表示します。行から列のピボットなど、実データの値で列が決まる処理は完全には復元できません。
- 未対応の加工・内部構造は警告や元のJSON定義で確認します。内部グループの展開表示は未実装です。
- 実データの値・件数・NULL率・分布は取得しません。通常の閲覧はデータソースへ接続しません。
- ローカルサーバーは `127.0.0.1` のみで待ち受けます。読み込んだファイルは保存用にPC上の一時領域で保持し、サーバー終了時に破棄します。フロー保存時は元の添付データも保持します。
- 画面からの読み込みは2GBまで、各定義ファイルは展開後64MBまでです。
- **共有HTMLには接続情報・計算式・フィルター値などの定義が入ります。** データ抽出や元パッケージの添付データ一式を埋め込むものではありません。

## ソースコードから起動・HTML変換（開発者向け）

Python 3.10以降を用意し、`start_viewer.cmd` または次のコマンドを実行します。

```powershell
python prepflow.py --serve
python prepflow.py --serve --port 8766
python prepflow.py "C:\flows\MyFlow.tflx" -o "output/MyFlow.html"
python prepflow.py "C:\flows\MyFlow.tflx" --open
```

`export_html.cmd` に1つのフローファイルをドロップしても変換できます。引数なしならファイル選択画面を開きます。開発用サーバーは端末で `Ctrl+C` を押して終了します。未保存の編集は、終了や再読み込み前に保存してください。

## Windows配布版をビルドする（開発者向け）

```powershell
python -m pip install --target .build-tools pyinstaller==6.22.3 pywebview==6.2.1 tableauserverclient==0.41
python build_windows.py
```

7-Zipと、開発環境の `build-password.txt` が必要です。パスワードファイルは配布しません。ビルドは `dist/PrepFlowViewer/` に本体・補助ファイルを生成し、`dist/v1.0_YYYYMMDD/` に `a.zip`（実行環境）と `b.zip`（EXE）を作ります。同じ版・同じ日のZIPは上書きします。

通常のビルドは最新の `manual.html` を `操作ガイド.html` としてコピーします。`--keep-manual` は以前の配布用ガイドを保持する指定なので、説明書更新を反映するときは使用しません。分割ZIPには補助ファイルを含めないため、操作ガイドなどは別途添付してください。

ユーザーのフロー、履歴、サンプル、テスト、認証情報は配布対象に含めません。依存ライブラリのライセンス文書は実行環境とともに同梱します。バージョンは `build_windows.py` の `VERSION` で管理し、現在は `1.0` です。
