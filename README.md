# PrepFlow Viewer

[![PrepFlow Viewerの主要操作デモ](docs/media/readme-demo.gif)](docs/media/readme-demo.gif)

約70秒で、閲覧・検索・計算式の編集・Undo / Redo・出力先の変更・HTML出力・言語切替を紹介します。Windowsのファイル選択・保存ダイアログは省略し、実行・Server公開は設定画面までを紹介しています。

Tableau Prepのフローファイル（`.tfl` / `.tflx`）を読み、フローマップ・フィールド・加工・計算式を確認するWindows用ツールです。Viewer本体では計算式・出力先の編集、フロー保存、出力ステップごとの実行、Tableau Serverへのパブリッシュができます。閲覧専用の単体HTMLを書き出して共有することもできます。

**仕様確認：2026年9月29日／現在のソース版 v1.0に対応**

基本操作は、一般ユーザー向けの [かんたん操作ガイド（HTML）](manual.html) を参照してください。「開く・見る・編集して保存・共有」の手順を短くまとめています。配布用の名前は `操作ガイド.html` で、オフライン閲覧・印刷に対応しています。詳しい仕様と開発者向けの情報は、このREADMEに記載しています。

## 利用できる機能

| 操作 | Windows版・ローカルサーバー版 | 書き出したHTML |
| --- | --- | --- |
| フロー図・フィールド・計算式・設定を読む | ○ | ○ |
| 計算式・出力先を編集してフロー保存 | ○ | — |
| 単一・一括でHTMLを出力 | ○ | — |
| 出力ステップを選んで実行 | ○（Tableau Prep Builderが必要） | — |
| Tableau Serverへフローをパブリッシュ | ○（接続先への認証が必要） | — |
| 表示言語を切り替える | 6言語 | 書き出し時に選んだ言語・設定の範囲 |

## 起動する

Windows 10 / 11（64ビット）とMicrosoft Edge WebView2が必要です。配布版にはPython実行環境を含むため、Python・Tableau Prep・Codexの追加インストールは不要です。通常の閲覧はオフラインで利用できます。フローの実行には、利用可能なライセンスで動作するTableau Prep Builderを別途インストールしてください。

1. [Releases](https://github.com/dirsense/PrepFlowViewer/releases) からWindows版の配布ZIPをダウンロードし、右クリック →「すべて展開」で展開します。
2. `_internal` と `PrepFlowViewer_v1.0.exe` が同じ階層にあることを確認します。
3. `PrepFlowViewer_v1.0.exe` を起動します。専用ウィンドウが開き、黒いコマンド画面は表示しません。
4. 「フローを開く」またはドラッグ＆ドロップで `.tfl` / `.tflx` を開きます。複数ファイルをドロップした場合は先頭の1ファイルを開きます。

フォルダーは任意の場所へ移せます。EXEと `_internal` は一緒に置いてください。配布ZIPには `操作ガイド.html`、`はじめに.txt`、`publish.example.ini` も含まれます。ZIPの中から直接EXEを実行せず、展開したフォルダーから起動してください。自分でビルドする必要はありません。

終了はウィンドウ右上の×です。未保存の編集があれば確認し、処理中は終了を止めます。専用ウィンドウごとに空いているローカルポートを使うため、別のViewerや普段のブラウザーには影響しません。ディスプレイごとの表示倍率に対応しています。

## 読み込み直後の表示と履歴

**フローを読み込んでも、入力ステップなどを自動選択しません。** 右側の初期タブは次のとおりです。

| 開き方 | 初期タブ |
| --- | --- |
| 前回ファイルがなく、空の状態で起動 | 使い方 |
| 空のViewerで最初のフローを開く | 使い方 |
| 書き出したHTMLをブラウザーで開く | 使い方 |
| 起動時に前回のフローを自動で読み込む | フロー情報 |
| 既にフローがある画面で別のフローを開く・ドロップする・履歴から切り替える | フロー情報 |

- 最近開いたフローは新しい順に最大10件。存在しないファイルは履歴から除外します。
- 履歴は `%LOCALAPPDATA%\PrepFlowViewer\recent-flows.json` に保存します。
- **デスクトップ版のドロップ**は元のパスを取得し、履歴と保存場所へ反映します。
- **通常のブラウザー版のドロップ**は元の絶対パスを取得できません。「フローを保存」で保存先を決めると履歴へ追加します。

## 表示言語を切り替える

Undo / Redoの右にある地球儀アイコンから、**日本語 / English / Français / Español / Deutsch / Português (Brasil)** の6言語を選べます。メニュー、詳細、使い方タブ、編集・保存・公開・実行の画面、Viewerの案内やエラー表示を切り替えます。開いているフロー、倍率、選択、確定済みの編集とUndo / Redo履歴は維持します。ステップ名・フィールド名・コメント・計算式・パスなどのフロー内のデータは翻訳しません。

初回はWindows／ブラウザーの優先言語から対応する言語を判定し、対応する言語がない場合や不明な場合は英語で開きます。フランス語・スペイン語・ドイツ語は地域にかかわらず各言語の翻訳を使い、ポルトガル語はブラジル版で表示します。IPアドレスや所在地は使いません。手動で選択した言語を次回以降は優先します。

Viewer本体は選択を `%LOCALAPPDATA%\PrepFlowViewer\language.json` に保存し、次回起動時に復元します。HTML出力フォームでは、埋め込む対応言語と「言語切替アイコン有」を指定できます。初期値は現在の表示言語だけ・アイコンなしです。アイコンなしでは単一選択、ありでは複数選択できます。「HTMLを出力」を開き直すと、単一出力・現在のフロー・現在の表示言語だけ・アイコンなしの状態に戻ります。HTMLは選択した言語だけを含み、初回は現在の表示言語（選択に含まれなければ先頭の言語）で開きます。アイコンありのHTMLで切り替えた言語はブラウザーに保存し、次回以降も同じ言語構成・初期言語のHTMLに適用します。Windows標準ダイアログの「開く」「保存」などのボタンはWindowsの表示言語に従い、Tableauやデータベースが返すログは原文のままです。

## フローマップと詳細を読む

- ステップをクリックすると詳細を表示し、関連する接続線を強調します。同じステップをもう一度押すか、マップの空白をクリックすると選択を解除して「フロー情報」に戻ります。
- 未選択時の右側には「フロー情報」「接続情報」「使い方」があります。「接続情報」では接続元ごとに入力ステップを確認し、その接続設定へ移動できます。
- 空白をドラッグして移動、ホイールでポインター付近を中心に細かく拡大・縮小します。空白のダブルクリックまたは上部の全体表示アイコンで全体を収めます。
- 左右の境界線で詳細パネルの幅を変更できます。全体表示中は幅に合わせて再調整し、手動で拡大・移動した後は倍率と位置を維持します。
- 画面下端にマップの操作案内を表示します。定義の解析時間は「フロー情報」で確認できます。

### タイトル・コメント

保存座標を基準に、閲覧用の間隔を設けて表示します。コメントの長さや開閉でステップを縦に押し広げることはありません。元ファイルの座標も変更しません。

- タイトルは画面上で最低14px、コメントは最低13px。ステップ上の加工アイコンは最低16pxを確保します。
- タイトルは周囲の空き幅に合わせて最大2行。省略時だけ、ステップにマウスを置くとタイトル全文を表示します。
- コメントの吹き出しアイコンで表示・非表示を切り替えます。初期状態はフローに保存された表示設定を反映します。
- **全角8文字分の幅が確保できない場合、コメント本文を表示しません。** 現在のフォントで幅を測るため、半角・全角が混じっていても単純な文字数判定にはなりません。
- 表示行数は周囲の空き領域に応じて決まります。マップ下端からは最大10行分の追加領域を使えますが、接続線や他のステップとの重なりは避けます。
- 先頭行が接続線などにぶつかる場合、近くの空き位置へ少し横にずらして表示を試みます。スペースが足りない場合は省略・非表示になります。
- 省略されたコメントは、本文または吹き出しアイコンにマウスを置くと全文を確認できます。本文が出ない場合も、表示をオンにした吹き出しアイコンから確認できます。

### フィールド・変更内容・設定

| タブ | 内容 |
| --- | --- |
| フィールド一覧 | フィールド名・型・計算式など。「すべて／使用中／削除済み」で絞り込み。削除済みは取り消し線で表示 |
| 変更内容 | 実行順の加工。「すべて／計算式／フィルター／その他」で分類し、フィールドや式を検索 |
| 設定（種類に応じて名称が変化） | 入力接続、左右の結合条件、ユニオンの入力ステップ、集計、ピボット、出力先・書き込みオプションなど |

入力ステップを選ぶと「フィールド一覧」、結合・ピボット・出力は設定タブ、それ以外は「変更内容」が最初に開きます。前後の矢印で接続先へ移動でき、候補が複数あるときは一覧から選びます。

## 出力先を編集する

出力ステップの「出力設定」→「出力先を編集」から変更します。編集対象はHyper・CSV・Excel・Tableau Serverです。JSONやデータベースなど、ほかの出力形式の編集には対応していません。

- **ファイル**：Hyper・CSV・Excelの切り替え、拡張子を除くファイル名、出力パスを指定します。Excelは31文字以内のシート名も指定できます。ファイル名には拡張子を入力せず、選んだ形式の拡張子を自動で付けます。空の出力パスはフローと同じ場所です。
- **Tableau Server**：Server URL・プロジェクトパス（`親/子`）・データソース名を指定します。サイトは既定固定です。パブリッシュ画面で保存した同じServerのトークンでプロジェクトを照会し、取得したIDを設定します。認証情報がない場合は「認証情報を設定」から認証テストを行います。フローの公開は不要です。「プロジェクトを確認」が成功してから確定します。既定サイト以外のServer出力をServer出力のまま編集することはできません。
- **書き込みオプションは変更不可**：現在の設定を維持します。維持できない形式への変更（例：追記設定の出力をCSVへ変更）は確定を止めます。

「変更を確定」で反映し、×・Esc・キャンセルは未確定の変更を破棄します。確定後は計算式と共通のUndo / Redoで戻せます。フロー保存・HTML出力・実行・パブリッシュにも確定内容を使います。Server URLやプロジェクトパスを変えたら、プロジェクトの再確認が必要です。トークンをフローや共有HTMLへ埋め込むことはありません。CLI実行に必要な認証JSONは実行画面で別途選択します。

## 計算式を編集する

一覧の式は最大6行で表示し、省略される式だけ展開・折りたたみボタンを表示します。拡大ボタンでポップアップを開き、「原文／自動整形」を切り替えて読めます。コピー、色分け、対応する括弧の強調にも対応しています。

1. 対象の式を拡大して編集します。入力中は `Ctrl+Z` / `Ctrl+Y`（または `Ctrl+Shift+Z`）で、その式の入力を戻す・やり直すことができます。
2. **「変更を確定」を押すとViewer内へ反映**します。元のフローファイルはまだ変わりません。
3. 上部のUndo / Redoで、複数の計算式にまたがる確定変更を戻す・やり直すことができます。計算式の変更なら対象の式が開き、出力先の変更なら対象ステップの出力設定を表示します。
4. 上部の出力・保存アイコン →「フローを保存」で保存先を選び、TFL / TFLXへ保存します。元と同じ拡張子で保存します。別名保存後はそのファイルが編集対象になります。保存成功時に確定履歴をリセットします。

**確定せずに×・Esc・ポップアップ外のクリックで閉じると、その未確定の編集は破棄します。** 開き直すと最後に確定した式に戻ります。破棄した入力は上部Undoの対象になりません。先に確定していた変更は残ります。

「自動整形」を見るだけでは変更になりません。そこで編集して確定した場合は、その編集内容を反映します。保存元を一意に特定できない式は確定できません。計算式の実行やTableauによる構文検証は行いません。

## 保存・共有・公開の違い

上部の下向き矢印（出力・保存）から「HTMLを出力」「フローを保存」を選びます。「HTMLを出力」は、共通の言語設定と「単一出力」「一括出力」のタブがあるフォームを開きます。初期タブは単一出力で、現在開いているフローが対象です。「フロー選択」で別のフローに変更してもViewerで開いているフローや編集履歴は変わりません。「HTMLを出力」を押すとWindows標準の保存画面を開きます。Undo / Redoは実行アイコンの右に常時表示し、履歴がないときは無効です。三角の実行アイコンから、出力ステップを選んでフローを実行できます。

Windowsの保存・ファイル選択・フォルダー選択は、アドレスバーと検索欄がある標準の選択画面を使います。HTML出力もViewer側で保存先を選ぶため、EXE版でも通常のブラウザーで開いた場合でも同じ操作です。

| 操作 | 反映先 | PC上のフローファイル |
| --- | --- | --- |
| 変更を確定 | Viewer内の変更・Undo履歴 | 変更しない |
| フローを保存 | 指定したTFL / TFLX | 同じ場所・名前なら上書き |
| HTMLを出力 | 現在のフローは確定内容、ファイル選択・一括出力は保存済み内容を使う閲覧用HTML | 変更しない |
| パブリッシュ | Tableau Server上のフロー | 変更しない |

「フローを保存」はダウンロードメニュー内に常にあり、未保存の確定変更があるときだけ押せます。Undo / RedoもViewer本体では常時表示されます。フロー保存をキャンセルしても、確定済みの編集はViewer内に残ります。読み込み後に元ファイルが外部で更新されていた場合は、上書きを止めます。

確定しただけの変更とUndo / Redo履歴は、画面を閉じたり再読み込みしたりしても残る自動保存ではありません。再起動後にも使う変更は「フローを保存」でファイルへ残してください。

出力したHTMLはPython・Viewer・ローカルサーバーなしで開けます。フロー図、検索、詳細、式のコピー・自動整形表示などを使えますが、編集・Undo / Redo・フロー保存・実行・パブリッシュはできません。元ファイルを移動しても閲覧でき、元ファイルの更新は自動反映しません。

## HTMLの一括出力

1. 出力・保存アイコン →「HTMLを出力」→「一括出力」タブを開きます。対応言語の設定は単一出力と共通です。
2. 複数のTFL / TFLXをフォームへドロップするか、「ファイル指定」「フォルダー指定」で追加します。フォルダーはサブフォルダーも含めるか選べます（初期値はオン）。
3. 出力先フォルダーを指定して「HTML一括出力」を押します。

一度に登録できるファイルは4,096件までです。選択したファイルの保存済み内容を、元ファイルと同じ名前のHTMLに変換します。同名のHTMLは上書きします。異なるフォルダーにある同名フローも、後から変換した内容で上書きします。画面で編集中の内容を含めたい場合は、先にフローを保存してください。

成功・失敗はファイルごとに表示し、失敗しても残りを続けます。「このファイルまでで停止」で次のファイルから停止できます。元フローと、現在開いているフローや編集履歴は変更しません。

## フローを実行する

1. 未確定の計算式があれば先に「変更を確定」し、上部の三角アイコンから実行画面を開きます。出力ステップがないフローではアイコンは無効です。出力ステップ名、保存先フォルダー、出力ファイル名を確認できます。
2. Tableau Prep Builderは標準のインストール先から自動検出します。見つからない場合や別の版を使う場合は「変更」で `scripts/tableau-prep-cli.bat` を選択します。
3. データベース・Tableau Serverなどの接続で必要な場合は、Prep CLI形式の認証JSONを選択します。Viewerのパブリッシュ用PAT設定とは別です。選択はViewerを終了するまで保持し、「解除」で外せます。
4. 各出力の「実行」でその出力だけ、「すべて実行」で全出力を一度に実行します。出力が多い場合は一覧内をスクロールできます。
5. 実行すると別のポップアップに実行状態・経過時間・ログを表示します。終了後は所要時間が残り、「前回の実行結果」から再確認できます。

実行中は「キャンセル」でViewerが起動した実行プロセスを停止できます。既に書き込まれたデータは元に戻りません。

確定済みの計算式・出力先の編集を含む一時コピーを使い、個別実行では他の出力ステップとその参照・表示設定だけを除きます。元フローと編集履歴は変更しません。「フローを開く」やデスクトップ版のドロップで開いた場合は、相対パスの基準を維持するため、一時コピーを元フローと同じフォルダーに作り、完了後に削除します。そのフォルダーへの書き込み権限が必要です。通常のブラウザー版でドロップしたフローは一時領域のコピーを使うため、相対パスを使うフローの実行前には「フローを開く」から元ファイルを選び直してください。

**実行は実データへ接続し、出力先をフローの書き込み設定に従って更新します。** 更新は完全更新で、パラメーターはフローの保存値を使います。増分更新やパラメーターの上書き指定は現在ありません。実行中は別の実行・フロー切替・編集を止め、ローカルサーバーが動いている間は、ブラウザーを再読み込みしても進行中の実行状況を再表示します。これは未保存の編集履歴を復元する機能ではありません。実行結果はViewerの起動中に保持し、終了後の一覧保存は行いません。

[Tableau公式のCLI実行手順](https://help.tableau.com/current/prep/ja-jp/prep_run_commandline.htm)

## Tableau Serverへパブリッシュする

全体表示アイコンの右にある上向き矢印から開きます。Viewer本体限定です。

1. Server URL、PATのトークン名・値を入力します。**サイトは既定サイト固定**で、サイト選択欄はありません。
2. 「認証テスト」でログイン・ログアウトを確認します。フローは公開しません。
3. パブリッシュ名と公開先を確認します。名前の初期値はファイル名（拡張子なし）、公開先は `親プロジェクト/子プロジェクト`。最上位だけならその名前を入力します。
4. 「パブリッシュ」を押し、フォームの実行ログで結果を確認します。**同じ公開先・同じ名前のフローは上書きします。** フローを実行する操作ではありません。

確定済みの編集を含む一時コピーを公開します。公開だけではPC上の未保存状態やUndo履歴は解除しません。公開先の初期値は、フロー自体に明示的で一意なプロジェクトパスがある場合だけ使用します。出力データソースの公開先は流用しません。

フォームは画面の高さに合わせて表示し、実行ログ領域を調整します。ログが長いときはログ内を、画面が小さくフォーム全体が収まらないときはダイアログをスクロールできます。

認証テストまたは公開成功時に、Server URL・トークン名・値をEXE横の `publish.ini` に保存します。ソース版はプロジェクト直下です。手動で用意する場合は `publish.example.ini` をコピーします。**トークンは設定ファイル内では平文**です。認証情報入りのファイルは配布物に含めないでください。設定のトークンをHTMLや実行ログへ埋め込むことはありません。

## 対応範囲とデータの扱い

- `flow` の処理定義、`displaySettings` の配置・色・表示設定、`maestroMetadata` のメタデータを読みます。
- `.tfl` はZIPパッケージとJSONの両方を受け付けます。保存座標がなければ接続から自動配置します。
- **フィールド一覧は定義からの静的な復元で、Tableauの実行結果ではありません。** 入力フィールドの定義不足や複雑な加工では実際のデータソースと一致しない場合があります。表示設定だけから完全な列一覧を保証するものでもありません。
- 名前変更・削除・型変更・計算・結合・ユニオン・集計・列から行のピボットなどを追います。結合前の左右の加工や、ユニオン入力ごとの式の違いも表示します。
- 型の推定は対応する式に限ります。判定できない型は「未確定」、復元に不確かさがある場合は注記を表示します。行から列のピボットなど、実データの値で列が決まる処理は完全には復元できません。
- 未対応の加工・内部構造は警告や元のJSON定義で確認します。内部グループの展開表示は未実装です。
- 実データの値・件数・NULL率・分布は取得しません。通常の閲覧はデータソースへ接続しません。
- ローカルサーバーは `127.0.0.1` のみで待ち受けます。読み込んだファイルは保存用にPC上の一時領域で保持し、サーバー終了時に破棄します。フロー保存時は元の添付データも保持します。
- ブラウザーのドロップ送信・一括追加のアップロードは1ファイル2GBまでです。各定義ファイルは展開後64MBまでです。
- **共有HTMLには接続情報・計算式・フィルター値などの定義が入ります。** データ抽出や元パッケージの添付データ一式を埋め込むものではありません。

## ソースコードから起動・HTML変換（開発者向け）

Python 3.10以降を用意し、`start_viewer.cmd` または次のコマンドを実行します。

```powershell
python prepflow.py --serve
python prepflow.py --serve --port 8766
python prepflow.py "C:\flows\MyFlow.tflx" -o "output/MyFlow.html"
python prepflow.py "C:\flows\MyFlow.tflx" --open
```

`export_html.cmd` に1つのフローファイルをドロップしても変換できます。引数なしならファイル選択画面を開きます。開発用サーバーは端末で `Ctrl+C` を押して終了します。未保存の編集は、終了や再読み込み前に保存してください。

## 構成と検証

画面側の改修箇所、共有状態、読み込み順は [画面コードの開発ガイド](web/README.md) を参照してください。JavaScript は描画・編集・ファイル操作などの役割で分割し、`web/assets.json` に読み込み順をまとめています。

```powershell
python -m unittest discover -s tests -v
npm ci

```

Node.js 22以降はJavaScriptの整形・検証用で、利用者のアプリ実行には不要です。`npm run format` で整形できます。Server連携の自動テストはモック・ローカル模擬Serverを使用します。Pythonの公開処理のテストには `tableauserverclient` が必要です。既存の `.build-tools` を使う場合は `$env:PYTHONPATH = (Resolve-Path .build-tools).Path` を設定してください。

## Windows配布版をビルドする（開発者向け）

```powershell
python -m pip install --target .build-tools pyinstaller==6.22.3 pywebview==6.2.1 tableauserverclient==0.41
python build_windows.py
```

ビルドは `dist/PrepFlowViewer/` に本体・実行環境・操作ガイドなどを生成し、`dist/PrepFlowViewer-v1.0-Windows-x64.zip` にまとめます。このZIPをGitHub Releasesの対応するバージョンへ添付します。同じバージョンのZIPがある場合は上書きします。

通常のビルドは最新の `manual.html` を `操作ガイド.html` としてコピーします。`--keep-manual` は以前の配布用ガイドを保持する指定なので、説明書更新を反映するときは使用しません。

ユーザーのフロー、履歴、サンプル、テスト、認証情報は配布対象に含めません。依存ライブラリのライセンス文書は実行環境とともに同梱します。バージョンは `build_windows.py` の `VERSION` で管理し、現在は `1.0` です。
