# Tableau Prep icons

`prep-icons.json` contains the original flow annotation SVGs and the path data for
the two pivot directions, taken from the locally installed Tableau Prep Builder
2026.2 assets at the user's request. These are Tableau/Salesforce assets, not
original artwork of this viewer.

Annotation assets: `Loom_Flow_Annotations_CalculatedField.svg`, `Filter.svg`,
`RemoveField.svg`, `Group.svg`, `RenameField.svg`, `ChangeDataType.svg` (same prefix).
Step assets: `Loom_Flow_Step_Pivot.As_React_Component.svg` and
`Loom_Flow_Step_Unpivot.As_React_Component.svg`.

The SVG geometry and original gray fills are preserved. Pivot accent fills use
the step color stored in the flow. HTML exports embed these assets directly.
