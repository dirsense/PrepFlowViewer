PrepFlow Viewer v1.0 — Windows

1. Extract the entire ZIP.
2. Open PrepFlowViewer_v1.0.exe. Keep the _internal folder beside it.
3. Open manual.html for the illustrated guide. Japanese: manual.jp.html.

Windows 10 / 11 (64-bit) and Microsoft Edge WebView2 are required.
Python and Tableau Prep are not required to inspect flows or exported HTML.
Running flows requires Tableau Prep Builder and a valid license. Running a
flow updates its output data; cancellation does not undo completed writes.

Use the globe button to choose a display language. Your selection is saved.
For Tableau Server publishing, credentials are saved in publish.ini after
successful authentication. Token values are stored as plain text. Do not
share that file. publish.example.ini is an optional configuration template.

Project: https://github.com/dirsense/PrepFlowViewer
Guide: https://dirsense.github.io/PrepFlowViewer/manual.html
